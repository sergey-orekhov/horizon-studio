# Launcher работает как пользовательский сервис, а не системный

Launcher, а значит и Agent, работает от имени пользователя ОС: LaunchAgent на macOS, `systemd --user` с linger на Linux, задача Task Scheduler на Windows. Системным сервисом (root / LocalSystem) он не является. Engine нужны учётные данные и окружение конкретного пользователя: `~/.claude`, git-конфиг, SSH-ключи, PATH. Файлы в Task Directory должны принадлежать этому пользователю, а для установки не должны требоваться права администратора.

## Consequences

На macOS Agent стартует только после входа пользователя в систему, поэтому на выделенной машине нужен автологин.
