# Launcher работает как пользовательский сервис, а не системный

Launcher, а значит и Agent, работает от имени пользователя ОС: LaunchAgent на macOS, `systemd --user` с linger на Linux, автозапуск при входе пользователя (`HKCU\…\Run`) на Windows. Системным сервисом (root / LocalSystem) он не является. Engine нужны учётные данные и окружение конкретного пользователя: `~/.claude`, git-конфиг, SSH-ключи, PATH. Файлы в Task Directory должны принадлежать этому пользователю, а для установки не должны требоваться права администратора.

## Consequences

На macOS и Windows Agent стартует только после входа пользователя в систему, поэтому на выделенной машине нужен автологин.

На Windows рассматривалась задача Task Scheduler «при запуске системы»: Agent стартовал бы до входа, но её создание требует прав администратора и сохранённого пароля пользователя, а после смены пароля задачу пришлось бы пересоздавать. Выбран запуск при входе. Launcher на Windows не перезапускается сам, если упадёт (на macOS и Linux это делают launchd и systemd), и останавливается без штатного завершения Agent: Session продолжатся при следующем старте.
