# The Agent works with Engines through a structured protocol, not a terminal

The Agent controls Engines through their structured interfaces (Claude Agent SDK, `codex exec --json` / app-server), not a raw PTY. Only this way can the Agent reliably detect the Waiting state, get the conversation id for resume (automatic continuation, Paused) and orchestrate several Sessions with different Roles. With a PTY, all of this would rely on parsing the screen. The cost is that each Engine needs its own adapter, and Engines with no structured mode are not supported. A separate shell console in the Task Directory may appear later as an addition, but not as a way to control an Engine.
