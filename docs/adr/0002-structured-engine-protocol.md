# Agent работает с Engine через структурированный протокол, а не через терминал

Agent управляет Engine через их структурированные интерфейсы (Claude Agent SDK, `codex exec --json` / app-server), а не через сырой PTY. Только так Agent может надёжно определить состояние Waiting, получить id разговора для resume (автопродолжение, Paused) и оркестрировать несколько Session с разными Role. При работе через PTY всё это держалось бы на парсинге экрана. Цена решения: для каждого Engine нужен свой адаптер, а Engine без структурированного режима не поддерживаются. Отдельная shell-консоль в Task Directory может появиться позже как дополнение, но не как способ управлять Engine.
